## Question 1: KDD vs Data Mining

### What is KDD?
KDD (Knowledge Discovery in Databases) is the complete process of finding useful knowledge from large amounts of data.

Steps of KDD:
1. Data Selection: choose the relevant data
2. Data Cleaning and Preprocessing: remove noise, errors and missing values
3. Data Transformation: convert data into a suitable form
4. Data Mining: apply algorithms to find patterns
5. Pattern Evaluation: check which patterns are useful
6. Knowledge Presentation: show the results in an understandable way

### What is Data Mining?
Data Mining is one step of the KDD process. It applies algorithms such as classification, clustering and association rules to the prepared data to find hidden patterns.

### Difference between KDD and Data Mining

1. Scope
   - KDD: It is the whole process of discovering knowledge.
   - Data Mining: It is only one step of the KDD process.

2. Includes
   - KDD: Includes cleaning, transformation, mining and evaluation.
   - Data Mining: Includes only pattern extraction.

3. Input
   - KDD: Takes raw data as input.
   - Data Mining: Takes preprocessed data as input.

4. Output
   - KDD: Gives useful and understandable knowledge.
   - Data Mining: Gives patterns and models.

5. Human involvement
   - KDD: High, needed at every stage.
   - Data Mining: Mostly driven by algorithms.

### Conclusion
Data Mining is a part of KDD, while KDD is the full process of turning raw data into useful knowledge.

## Question 2: Structured vs Unstructured Dataset

### What is a Structured Dataset?
A structured dataset is data that is organized in a fixed format, usually in rows and columns, so it is easy to store, search and analyze.

Examples: student marks table, bank records, Excel sheets, SQL databases.

### What is an Unstructured Dataset?
An unstructured dataset is data that does not have a fixed format or model, so it is harder to store and analyze.

Examples: images, videos, audio, emails, social media posts, PDF documents.

### Difference between Structured and Unstructured Dataset

1. Format
   - Structured: Has a fixed format, in rows and columns.
   - Unstructured: Has no fixed format.

2. Storage
   - Structured: Stored in relational databases and spreadsheets.
   - Unstructured: Stored in data lakes, file systems and NoSQL databases.

3. Examples
   - Structured: Student marks table, bank records.
   - Unstructured: Images, videos, emails, social media posts.

4. Searching
   - Structured: Easy to search using SQL.
   - Unstructured: Difficult to search, needs special tools.

5. Analysis
   - Structured: Can be analyzed with simple tools and algorithms.
   - Unstructured: Needs NLP, image processing or machine learning.

### Conclusion
Structured data is organized and easy to analyze, while unstructured data has no fixed format and needs advanced tools to analyze.
